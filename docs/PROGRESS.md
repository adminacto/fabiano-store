## PHASE 2 🟡 — UI/UX (часть 1: дизайн-система, layout, главная)

Сделано:
- Дизайн-система: токены палитры из ТЗ, Cormorant Garamond + Manrope (латиница, узбекские `oʻ gʻ`, кириллица), кнопки, skeleton, reduced-motion.
- Локализация uz (по умолчанию) / ru / en: next-intl, префиксы URL, переключатель языка, 60 ключей, одинаковых во всех языках.
- Header: desktop-навигация, прозрачный режим поверх hero с фото, полноэкранное мобильное меню (области нажатия ≥ 44 px, Esc, блокировка прокрутки).
- Главная: hero (из `HeroBanner` в Dashboard; без фото — типографический вариант), New Arrivals, Featured Collections, Best Sellers (только при реальных продажах), Brand Section, Newsletter.
- Newsletter: server action → PostgreSQL, Zod-валидация, honeypot, rate limit.
- Footer, 404, error и loading-состояния, robots.txt.
- Ядро бизнес-логики с тестами: деньги без float, формат сумов по локали, телефоны +998, расчёт корзины, промокоды, бесплатная доставка, слияние корзин, статусы заказа.
- Seed: роли, размеры, цвета, категории Men/Women, 5 коллекций, настройки, все платёжные методы выключены. Без фиктивных товаров и заказов.

Решения, принятые без заказчика:
- Палитра — нейтральная из ТЗ. Логотип — текстовый wordmark; загруженный в Dashboard SVG заменяет его автоматически. Бордовый `#5C1A24` добавлен как цвет товара, а не как цвет интерфейса.

Проверено:
- `npm run test:unit` — 13/13.
- `npm run test:db` — ограничения и складская логика на PostgreSQL 16.
- Строгая проверка типов модулей бизнес-логики.

**Не проверено:** `next build` и рендер страниц. В среде разработки не было сетевого доступа для установки Next.js и Prisma, поэтому React-компоненты написаны, но ещё не собирались. Первым шагом при появлении доступа: `npm install && npx prisma generate && npm run typecheck && npm run build`.


## PHASE 2 🟡 — часть 2: каталог, страница товара, корзина

Сделано:
- **Каталог**: `/men`, `/women`, `/men/[category]`, `/women/[category]`, `/catalog` (в т.ч. `?new=1`, `?sale=1` из меню), `/collections`, `/collections/[slug]`, `/search`.
  - Фильтры: категория, цена, размер, цвет, бренд, коллекция, наличие, скидка, новинки. Размер+цвет+наличие проверяются в одном варианте.
  - Сортировка: рекомендуемые, новые, цена ↑/↓, бестселлеры. Пагинация по 24 со стабильным порядком.
  - Поиск по названию, описанию, составу, категории (в текущем языке) и точному артикулу.
  - Фильтры — GET-форма: работают без JavaScript, URL можно отправить. Desktop — боковая панель с автоприменением, mobile — нижняя шторка.
  - SEO: canonical, `noindex` для отфильтрованных вариантов, хлебные крошки + JSON-LD BreadcrumbList, `sitemap.xml` со всеми языками.
- **Страница товара** `/product/[slug]`: галерея (миниатюры, свайп на мобильном, полноэкранный zoom за курсором), выбор цвета меняет галерею и URL (`?color=`), размеры с состоянием «нет в наличии», Size Guide, остаток, Add to Cart, Buy Now, Share (системное меню или копирование ссылки), описание/состав/уход, похожие товары, JSON-LD Product, Open Graph, hreflang.
  - Кнопка TRY IT ON LIVE показывается только при включённых флагах и активна только при зарегистрированном движке SDK; без SDK примерка не имитируется.
- **Корзина**: подписанная HMAC cookie для гостя (подделать id чужой корзины нельзя), REST API (`/api/v1/cart`, `/items`, `/items/:id`, `/coupon`, `/count`), проверка остатков при добавлении и изменении, смена размера и цвета прямо в корзине (с объединением одинаковых строк), промокоды с понятными ошибками, доставка от первого включённого курьерского способа, счётчик в header, красивая пустая корзина, фиксированная панель итога на мобильном.
  - Слияние гостевой корзины с корзиной пользователя (`mergeGuestCartIntoUser`) готово, вызывается при входе (PHASE 3).
  - CSRF-проверка origin и rate limit на изменяющих запросах; подбор промокодов ограничен (10 за 10 минут).

Проверено: 31/31 unit-тестов (+ фильтры, варианты товара, подпись cookie), тесты БД, строгая проверка типов чистой логики, синтаксический разбор всех 70 файлов TS/TSX.

**Пока не работает:** кнопки «Оформить заказ» и Buy Now ведут на `/checkout`, которого ещё нет (404) — следующий шаг. Wishlist появится вместе со входом в аккаунт. `next build` по-прежнему не запускался.
